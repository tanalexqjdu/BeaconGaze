# BeaconGaze

BeaconGaze is a Geo-distributed, event-driven platform that processes real-time data with auto-scaling, making systems aware.

With BeaconGaze, you get a lightweight tool that stays out of your way.

**What you get**

- BeaconGaze is a Geo-distributed, event-driven
- platform that processes real-time data
- with auto-scaling, making systems aware

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/BeaconGaze.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
